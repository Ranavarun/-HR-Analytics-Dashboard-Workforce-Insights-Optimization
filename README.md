# -HR-Analytics-Dashboard-Workforce-Insights-Optimization


As part of my HR Analytics project, I developed a dashboard to analyze employee data, workforce trends, and HR policy effectiveness, leveraging Excel and SQL for data-driven decision-making.

🔍 Key Highlights & Insights:
✅ Employee Data Management:

Structured and organized workforce data in Excel, ensuring data accuracy and consistency for effective HR decision-making.
✅ SQL for Workforce Insights:

Queried and analyzed HR databases to track key metrics like employee turnover, retention rates, and payroll trends, providing actionable insights.
✅ HR Policy Impact Assessment:

Assessed the effectiveness of HR policies by analyzing employee well-being, career development programs, and engagement trends, identifying areas for improvement.
🚀 Impact & Takeaways:
By leveraging data analytics in HR, this project helped uncover key insights to enhance employee satisfaction, optimize workforce planning, and improve retention strategies.
